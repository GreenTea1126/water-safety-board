# 수상안전팀 업무보드

팀 공용 업무보드의 소스 코드입니다. Claude 아티팩트로 배포해 팀원끼리 실시간으로 함께 씁니다.

## 기능
- **업무 목록**: 담당자·확인자 지정, 우선순위, 마감일, 확인 대기 → 확인 완료 흐름
- **정기업무**: 매주/매월 반복 업무 자동 표시 (공휴일·주말 보정)
- **유효기간 관리**: 허가 등 만료일 추적, 만료 전 안내 시점 알림
- **메모**: 팀 공용 메모와 복사 기능
- **담당자 필터**: 내 업무만 보기
